#Orders realtions
User → Orders: One user can have many orders.
Order → User: Each order belongs to one user.
Order → OrderItems: One order can contain many products/items.
OrderItem → Order: Each item belongs to one order.
OrderItem → Product: Each item points to one product.
Product → OrderItems: One product can appear in many order items.
